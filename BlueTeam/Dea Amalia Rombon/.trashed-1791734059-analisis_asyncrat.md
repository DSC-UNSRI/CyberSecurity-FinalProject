# 🛡️ Blue Team Defensive Security Report: AsyncRAT Malware Analysis

Dokumen ini berisi laporan hasil analisis malware yang saya lakukan sebagai bagian dari Cyber Security Final Project di GDGoC UNSRI.

## 📌 Executive Summary

Pada analisis kali ini, saya meneliti sebuah file mencurigakan berformat .zip yang disamarkan sebagai dokumen hukum/tagihan (OFICIO_REITERADO_TUTELA). File ini diunggah oleh penyerang ke layanan penyimpan file publik (Filestack CDN) untuk mengelabui filter keamanan internet.

**Bagaimana cara kerja serangannya?**

Korban mengunduh file .zip dari internet.
Lalu korban membuka isi file .zip tersebut menggunakan WinRAR.
Di dalam folder hasil ekstraksi, terdapat file script JavaScript (.js). Saat file ini diklik, sistem Windows tidak membukanya sebagai teks biasa, melainkan langsung menjalankannya lewat program bawaan Windows (Windows Script Host / wscript.exe).
Script jahat tsb lalu "menyuntikkan" muatan malware AsyncRAT ke dalam proses resmi Windows bernama RegAsm.exe.
Setelah berhasil masuk ke RegAsm.exe, penyerang bisa mengendalikan komputer korban dari jauh, mencuri password yang tersimpan di browser, hingga merekam ketikan keyboard (keylogging).

## 📊 Kronologi & Process Tree

Berdasarkan pemantauan pada dashboard sandbox ANY.RUN, berikut adalah alur eksekusi proses dari awal sampai malware menguasai sistem:

```
[1. chrome.exe] ── (Download file ZIP dari web)
       │
       ▼
[2. WinRAR.exe] ── (Membuka & mengekstraksi OFICIO_REITERADO_TUTELA.zip)
       │
       ▼
[3. wscript.exe] ── (Jalankan script OFICIO_REITERADO_TUTELA.js di folder %Temp%)
       │
       ▼
[4. RegAsm.exe] ── (PID: 8400 - Disuntik malware AsyncRAT & kirim data ke penyerang)
```

**Penjelasan:**

- chrome.exe: Browser yang digunakan korban untuk mengunduh file pancingan dari Filestack CDN.
- WinRAR.exe: Aplikasi yang dipakai untuk mengekstraksi file .zip.
- wscript.exe: Program resmi bawaan Windows untuk menjalankan script. Penyerang sengaja memanfaatkan fitur asli sistem (Living off the Land) agar aksinya tidak dicurigai oleh antivirus tradisional.
- RegAsm.exe: Merupakan utilitas resmi milik Windows (.NET Assembly Registration Tool). Namun, oleh wscript.exe, memori internal RegAsm.exe dibongkar dan diganti dengan kode jahat AsyncRAT (Process Hollowing). Dari luar terlihat seperti program Windows biasa, tetapi dalamnya sudah sepenuhnya dikendalikan peretas.

## 💡 Rekomendasi Mitigasi & Pencegahan

Berdasarkan temuan di atas, berikut langkah-langkah pencegahan yang saya sarankan untuk mengamankan jaringan dan komputer:

1. **Ubah Asosiasi Default File .js:**
   Ubah aplikasi bawaan pembuka file .js dari wscript.exe menjadi Notepad. Dengan begitu, jika pengguna tidak sengaja mengklik file script, filenya hanya akan terbuka sebagai dokumen teks biasa tanpa mengeksekusi kode berbahaya.

2. **Batasi Eksekusi Script dari Folder Temp:**
   Gunakan kebijakan sistem (Group Policy Object / GPO) untuk melarang eksekusi file script (.js, .vbs, .bat) yang berjalan langsung dari direktori %AppData%\Local\Temp.

3. **Penerapan EDR / SIEM Detection Rules:**
   Buat aturan deteksi pada sistem EDR/SIEM untuk memberikan peringatan (alert) apabila ada program wscript.exe yang memicu pembuatan proses baru pada RegAsm.exe atau utilitas .NET lainnya.

4. **Pengisolasian Perangkat & Reset Password:**
   Jika ada perangkat yang terinfeksi sampel ini, segera lakukan isolasi jaringan dan lakukan perubahan password massal (forced password reset) untuk semua akun yang pernah dibuka pada komputer tersebut.
